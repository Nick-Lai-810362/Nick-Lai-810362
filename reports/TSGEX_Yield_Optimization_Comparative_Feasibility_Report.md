## 2. 執行摘要（Executive Summary）

### 2.1 提案背景

TSGEX 資產管理部長期持有相當規模之公司自有美元／穩定幣流動資金，用以支應日常營運調度與策略性資本配置。在銀行體系美元活存利率有限、且加密貨幣市場提供多元「類固收」與「結構型」收益工具的環境下，本部門就市場上三類主流收益增強工具進行**橫向對比與財務風險穿透分析**，以協助財務部與風控委員會就資金配置方案做出審慎決策。

### 2.2 策略定位：三類產品之收益光譜定位

本報告評估之三項標的，雖經常被市場行銷語言統稱為「加密貨幣理財」，惟其底層金融工程本質差異極大，財務部審查時應嚴格區分：

| 光譜位置 | 產品 | 收益本質 | 本金保障屬性 |
|---|---|---|---|
| **① 純固定收益（Fixed-Income-Like）** | Bitfinex USD Margin Funding | 出借利息（Interest Income），P2P 超額抵押借貸 | 本金不因市場方向而變動，僅承擔交易對手信用風險 |
| **② 資金池活期收益（Pooled Deposit-Like）** | Binance / OKX USDT 活期理財 | 資金池借貸利差，類活存 | 名目上本金穩定，惟隱含交易所表內信用曝險與利率稀釋問題 |
| **③ 賣方結構型衍生品（Short-Option-Like）** | Binance / OKX 雙幣理財 | **賣出選擇權之權利金（Option Premium）**，非利息 | **非保本**，本金可能被迫轉換為貶值資產，屬方向性賭注 |

**核心結論先行揭露：** 僅有第①類（Bitfinex USD Margin Funding）在風險屬性上符合公司自有流動資金「本金優先、收益其次」之管理原則，可作為主力配置；第②類僅適用於極小額、極短天期之營運調度緩衝；第③類因涉及非對稱下行風險與嵌入式衍生工具會計複雜度，**建議不予准入**。

### 2.3 核心財務目標

| 指標 | 數值 |
|---|---|
| **財務基準指標（Hurdle Rate）** | SOFR / 3M T-Bill ≈ 4.5% + 150–200 bps 流動性溢價 |
| **目標淨年化收益率（Net APY）** | **6.0% – 8.0%+**（僅適用於主力配置標的） |
| **百萬美元規模資金效率門檻** | 任一標的之**百萬美元實際有效年化（Effective APY）**須顯著高於財務基準，方具配置價值 |

### 2.4 結論摘要

1. **Bitfinex USD Margin Funding**：於百萬美元規模下仍可維持 5.0%–12.0%+ 之淨年化收益，**收益本質清晰、風險可控、會計入帳最單純**，建議作為主力配置標的。
2. **Binance / OKX USDT 活期理財**：受「階梯利率陷阱」影響，百萬美元規模之實際有效年化僅約 **1.5%–3.5%**，遠低於行銷頁面所示之 10%+ 頭牌利率，**資金效率低落，僅適合作為極小額 T+0 應急調度池**。
3. **雙幣理財（Dual Investment）**：本質為出售選擇權賺取權利金，**存在本金非對稱下行虧損風險**，且會計上須認列為嵌入式衍生工具（Embedded Derivatives, FVTPL），評價與稽核複雜度高，**與公司自有流動資金「資本保全優先」之管理原則相悖，建議明確排除於配置範圍之外**。

## 3. 標的產品架構與運作機制深度剖析（Product Deep Dive）

### 3.1 Bitfinex USD Margin Funding

| 項目 | 內容 |
|---|---|
| **成立歷史** | 2012 年成立，為全球現存歷史最悠久、美元 P2P 保證金融資出借市場深度最深之平台，歷經多次極端行情壓力測試（2020 年 3 月閃崩、2022 年 LUNA/FTX 信用事件）未發生出借人系統性損失 |
| **撮合機制** | 公開訂單簿（Order Book）P2P 直接撮合，出借人掛出「金額、利率、天期」，依價格與時間優先原則自動成交，資訊透明度高 |
| **超額抵押率（Over-collateralization）** | 借款人須先存入超額擔保品方可動用融資額度：原始保證金率約為部位名目價值之 15%–33%（最高槓桿 3–6.6 倍），維持保證金率通常約 15% 上下 |
| **清算引擎（Liquidation Engine）** | 當保證金比率跌破維持保證金率時，系統自動觸發強制減倉／平倉，優先以借款人擔保品（而非出借人本金）償付未平倉融資本息 |
| **出借人優先受償權** | 融資出借人對借款人擔保品之求償順位優先於借款人自身權益，只要強平引擎於保證金比率歸零前完成減倉，出借人本金即不受影響 |
| **為何選擇 USD 法幣而非代幣** | (1) 零幣價波動（Delta-Neutral），本金無方向性曝險；(2) 會計入帳可直接列示為短期金融資產／應收利息，符合 GAAP/IFRS 現金及約當現金認列規範；(3) 完全規避穩定幣發行商儲備金與脫錨風險 |

### 3.2 Binance / OKX USDT 活期理財（Simple Earn / 餘幣寶）

| 項目 | 內容 |
|---|---|
| **運作機制** | 用戶存入 USDT 至交易所之「資金池」，交易所將資金池統一運用於：(a) 借予保證金交易者、合約交易對手方；(b) 內部做市與流動性調度；(c) 部分轉投其他機構借貸管道賺取利差，交易所再依「階梯利率」支付用戶利息，賺取中間利差 |
| **表內資產負債表調度** | 用戶存入之 USDT **並非隔離於用戶專屬帳戶**，而是併入交易所整體資金池，於交易所財務報表上構成**表內負債（用戶應付款項）**，交易所對其自由調度運用，用戶本質上承擔**對交易所整體之無擔保信用曝險（Unsecured Exposure）**，而非對特定借款人之有擔保債權 |
| **儲備金證明（Proof of Reserves, PoR）** | 主流交易所定期發布資產儲備證明，惟其查核範圍、頻率與獨立性參差不齊，多數 PoR 僅涵蓋特定時點之資產快照，**不等同於持續性、審計等級之資產負債表查核**，無法完全消弭資金挪用或表外負債風險 |
| **保護基金機制（SAFU / Protection Fund）** | 部分交易所設有保護基金（如 Binance SAFU）用以吸收極端事件損失，惟基金規模相對其總資產管理規模（AUM）占比有限，**不足以覆蓋交易所倒閉等系統性尾部風險** |
| **階梯利率結構（Tiered APR）之本質** | 交易所行銷頁面所展示之「10%+ 高年化」，**僅適用於前 500–1,000 USDT 之極小額度**，超過門檻後利率**斷崖式下降**至 1.5%–3.5% 浮動基礎利率區間，此設計本質上是**獲客行銷成本**（Customer Acquisition Cost），而非可規模化之機構收益方案 |

### 3.3 Binance / OKX 雙幣理財（Dual Investment / 雙幣贏）

| 項目 | 內容 |
|---|---|
| **金融工程本質** | 雙幣理財之底層結構為投資人**出售一組選擇權（Short Option）**予平台：「低買（Buy Low）」結構本質為**賣出看跌期權（Short Put）**；「高賣（Sell High）」結構本質為**賣出看漲期權（Short Call）**。投資人收取之「高年化利率」實質為**選擇權權利金（Option Premium）**的年化換算，而非利息 |
| **行權價與行權日規則** | 投資人於申購時選擇「行使價格（Strike Price）」與「交割日（Settlement Date）」；到期時平台依當時市場價格與行使價之相對關係，決定是否對投資人「行權」：<br>• 若市場價格未觸及行使價（價外到期）：投資人取回原幣本金 + 權利金<br>• 若市場價格觸及或穿越行使價（價內到期）：投資人**本金將被強制依行使價轉換為另一種計價資產**（即便該資產當時市價已低於行使價），本金因此產生實質減損 |
| **高年化之定價拆解** | 例：某雙幣理財產品標示「年化 45%」，天期 7 天，其權利金收入換算為單期收益率僅約 0.86%（45% × 7/365）。此收益率之所以能達到 45% 年化水準，**恰恰反映市場隱含波動率（Implied Volatility）極高，亦即該資產於此期間發生劇烈價格波動、導致投資人被迫「接刀」之機率不容忽視**——高年化與高尾部風險為同一枚硬幣的兩面，並非「免費午餐」 |
| **非對稱下行風險** | 上檔收益被**權利金封頂**（無論標的漲多少，投資人最多只拿到本金+固定權利金），下檔虧損卻**理論上無下限**（標的可跌至趨近於零），此為**嚴重非對稱之風險報酬結構（Negatively Skewed Payoff）**，與傳統「風險越高、上檔期望報酬亦應等比例提高」之風控直覺相悖 |

- **試算本金：** USD／USDT 1,000,000（公司自有資金規模）
- **目的：** 揭露行銷頁面「頭牌利率」與機構大額資金「實際有效年化（Effective APY）」之落差

### 4.2 Bitfinex USD Margin Funding：三情境試算（扣除平台 15% 服務費後）

| 情境 | 淨年化收益率（Net APY） | 年度預期淨利（USD） | 月度預期淨利（USD） | 相較 SOFR（4.5%）超額利差 |
|---|---|---|---|---|
| **保守情境**（市場冰河期） | **5.0%** | $50,000 | $4,166.7 | +50 bps |

#### 隱含期望值（EV）示意性情境權重試算

> 以下機率權重**純屬示意性情境分析，用以呈現風險報酬形狀之非對稱性，並非機率預測或市場觀點**。

| 情境 | 假設機率 | 單週報酬率 | 機率加權貢獻 |
|---|---|---|---|
| 價外到期（僅收權利金） | 82% | +0.86% | +0.71% |

## 5. 財務部專題：資產分類、會計處理與外部審計（Accounting & Audit Implications）

### 5.1 會計科目認列對比

| 比較維度 | Bitfinex USD 放貸（美元法幣） | Binance/OKX USDT 活期理財 | 雙幣理財（Dual Investment） |
|---|---|---|---|
| **建議會計科目** | 現金及約當現金 / 短期金融資產（定期存款性質） | 虛擬資產（Digital Asset）存貨或無形資產，部分準則下列為金融資產 | **嵌入式衍生工具（Embedded Derivative），應以公允價值列入損益（FVTPL）** |
| **計價貨幣風險** | 無（美元法幣，零脫錨風險） | 有（USDT 儲備金與脫錨風險） | 有（雙重：計價幣別 + 選擇權標的資產雙重波動） |
| **公允價值評價頻率** | 不需頻繁重評價（面額計價，僅需認列應計利息） | 需依資產負債表日市價評價，若採無形資產模式甚至僅能認列減損、不得迴轉增值 | **每報告期均須以選擇權定價模型（如 Black-Scholes）重新評價，複雜度最高** |
| **減損測試（Impairment Test）** | 不適用（法幣無減損問題，僅需評估交易對手信用減損） | 適用，需定期執行虛擬資產減損測試 | 適用於嵌入式衍生工具之公允價值減損，且需拆解主合約與衍生工具分別評價 |
| **審計複雜度（相對排序）** | **低** | 中 | **高** |

### 5.2 外部審計（Big 4 等級）查核重點

| 查核面向 | Bitfinex USD 放貸 | CEX USDT 活期理財 | 雙幣理財 |
|---|---|---|---|
| **存款函證（Confirmation）難易度** | 中等——離岸交易所配合函證程序尚待逐案協調，惟資產性質單純（法幣餘額 + 應計利息），函證內容清晰 | 中等偏難——需同時函證本金餘額與應計利率結構，且需向平台索取階梯利率適用明細佐證 | **高難度**——需另外取得選擇權合約條款、行使價、結算機制之第三方佐證文件，函證範本市場尚未標準化 |
| **公允價值評估工作** | 極少（僅應計利息之簡單估算） | 中等（虛擬資產市價之外部報價來源比對） | **繁重**（須聘請衍生性商品評價專家或採用平台提供之模型並進行獨立覆核） |
| **合規成本（審計簽證費用增量，相對排序）** | 低 | 中 | **高** |
| **法遵室額外關注項** | 是否構成非受監管之跨境資金拆放 | 平台 PoR 揭露品質、資金池挪用風險之內控佐證 | **是否構成未經核准之衍生性商品交易，是否逾越公司資金運用授權範圍** |

## 6. 全面風險矩陣與情境壓力測試（Comprehensive Risk Matrix）

### 6.1 四大風險構面橫向對比

| 風險構面 | Bitfinex USD Margin Funding | Binance/OKX USDT 活期理財 | 雙幣理財（Dual Investment） |
|---|---|---|---|
| **① 交易對手信用與倒閉託管風險（Counterparty Risk）** | 中——資金存放單一平台，惟出借部位有借款人超額擔保品作為緩衝，且出借人具優先受償權 | **中高**——資金併入交易所表內資金池，用戶對交易所整體構成無擔保信用曝險，倒閉時求償順位劣後 | 中高——同樣依附於平台信用，且合約結構更複雜，倒閉情境下之求償與結算爭議風險更高 |
| **② 市場方向與本金虧損風險（Delta / Market Risk）** | **無**——本金以美元法幣計價，出借行為不涉及標的資產價格方向性曝險 | 低——本金以 USDT 計價，主要風險為 USDT 自身脫錨，非市場方向性曝險 | **高**——本金可能被迫按不利價格轉換為貶值資產，具完整方向性風險曝險 |
| **③ 流動性鎖定與贖回限制（Liquidity Lock-up）** | 中——天期屆滿前不可單方面提前贖回，惟可透過短天期階梯設計主動管理 | **低**——多數活期產品支援即時或 T+1 贖回，流動性最佳 | 中——鎖定至結算日，且結算前無法取消或部分贖回 |
| **④ 極端黑天鵝事件壓力測試** | 承作充分超額抵押部位，且平台設有風險準備金（Insurance Fund）吸收穿倉損失，本金減損機率極低 | 交易所單日擠兌／倒閉情境下，用戶本金可能大幅減損甚至歸零（見下方壓力情境） | 單日崩跌情境下，本金依行使價強制轉換，**可實質承受與現貨市場相同幅度之下跌損失**，權利金收入無法覆蓋深度下跌 |

### 6.2 極端情境壓力測試（單一事件衝擊試算，$1,000,000 本金）

| 壓力情境 | Bitfinex USD 放貸 | CEX USDT 活期理財 | 雙幣理財 |
|---|---|---|---|
| **標的資產單日崩跌 40%** | 無直接影響（本金為美元，惟需留意借款人集中違約機率上升，緩釋依賴強平引擎與超額抵押機制） | 無直接影響（USDT 計價），惟市場恐慌可能引發交易所擠兌，間接推升流動性風險 | **重大衝擊**——若行使價未設定足夠安全邊際，本金可能依行使價強制轉換為大幅貶值資產，單一事件損失可達本金 20%–40%+ |
| **USDT 脫錨 3%** | 不適用（本策略不持有 USDT） | **本金直接減損約 3%**，且若脫錨事件延續，贖回時可能面臨額外折價或平台暫停出金 | 若計價貨幣為 USDT，同樣面臨約 3% 直接減損，且與標的資產波動風險疊加 |
| **交易所擠兌 / 無預警倒閉** | 中度衝擊——曝險上限已控制在總資產 10%–15%，且出借部位仍有借款人擔保品可供追償，惟平台若倒閉可能影響資金取回時效 | **重大衝擊**——資金池模式下，用戶求償順位通常劣後於平台其他債權人，本金可能大幅減損甚至全損 | 重大衝擊——除本金求償問題外，尚須面對未結算衍生性合約之法律定性爭議，追償複雜度最高 |

## 7. 綜合決策矩陣與資產管理部配置建議（Strategic Recommendations）

### 7.1 跨維度決策對比表

| 對比維度 | Bitfinex USD Margin Funding | Binance/OKX USDT 活期理財 | 雙幣理財（Dual Investment） |
|---|---|---|---|
| **標的資產** | 美元法幣（USD） | 穩定幣（USDT） | 加密貨幣現貨 + 選擇權（USDT/BTC/ETH 等） |
| **計價幣別風險** | 無 | 有（脫錨風險） | 有（脫錨 + 標的雙重波動） |
| **收益本質** | 利息收入（Interest Income） | 利息收入（惟遭階梯稀釋） | **選擇權權利金（Option Premium）** |
| **百萬美元規模 Effective APY** | **5.0% – 12.0%+** | **1.5% – 3.5%** | 名目 20%–60%+，惟**非保本，隱含尾部虧損可達兩位數百分比** |
| **本金保障屬性** | 本金不受市場方向影響 | 名目本金穩定（惟承擔平台信用曝險） | **非保本，方向性風險完全由投資人承擔** |
| **Delta / 市場方向風險** | 無 | 低（僅脫錨風險） | **高（完整方向性曝險）** |
| **流動性召回週期** | 天期內鎖定（可透過階梯設計管理，2–120 天彈性） | 即時 / T+1（最佳） | 鎖定至結算日，無法提前贖回或取消 |
| **財務入帳複雜度** | **低**（現金及約當現金／短期金融資產） | 中（虛擬資產存貨，需減損測試） | **高**（嵌入式衍生工具，FVTPL，需選擇權評價模型） |
| **與公司資金管理原則相容性** | **高度相容** | 部分相容（僅限極小額緩衝用途） | **不相容** |

### 7.2 資產管理部具體配置方案

> #### 【主力配置】Bitfinex USD Margin Funding
> - 設定**單一平台總自營曝險上限：資產管理部可運用美元總資產之 10%–15%**
> - 採用「利差階梯配置機制」：常態市場（APR < 15%）以 2–7 天短天期滾存為主；高息溢價期（APR ≥ 15%）開放至 15–30 天中天期鎖定；極端行情（APR ≥ 30%+）由交易員專案授權配置至 60–120 天
> - 實施階梯式到期（Laddering），確保每一營業日均有部分資金到期回流，兼顧收益與流動性安全邊際

> #### 【輔助備用】Binance / OKX 小額活期理財
> - **僅作為 T+0 緊急營運調度池**使用，額度嚴格控制在「階梯利率頭牌區間」內（例如單一平台不超過 500–1,000 USDT 等值之象徵性額度，或視個案營運調度需求另行核定極低額度上限）
> - 不作為收益增強策略之主力工具，其存在目的僅為**保留即時流動性**，任何超出即時調度需求之閒置資金**不應**留存於此類低效率資金池

> #### 【禁止准入】雙幣理財（Dual Investment）
> - 因具備**實質市場方向性賭注本質**與**選擇權被動行權之非對稱下行風險**，不符合公司自有流動資金「資本保全優先、收益其次」之核心管理原則
> - 會計上構成嵌入式衍生工具，評價與稽核複雜度高，亦可能觸及法遵室對「未經授權衍生性商品交易」之合規疑慮
> - **建議資產管理部投資政策明文將雙幣理財（及同類結構型期權產品）列入禁止配置清單（Prohibited Instrument List）**

## 8. 內控架構、資安規範與三階段落地時程（Governance & Roadmap）

### 8.1 API 資安防禦架構（適用於主力配置標的 Bitfinex）

| 防禦層 | 具體措施 |
|---|---|
| **最小授權架構** | API 金鑰僅開放 `Margin Funding` 讀寫權限，**物理性封鎖 `Withdrawal`（提幣）與 `Transfer`（轉帳）功能** |
| **網路存取控制** | 固定 IP 白名單綁定，僅允許自公司內部 VPC 固定出口 IP 存取 API |
| **金鑰保管** | 金鑰採 KMS（Key Management Service）加密保管，產生、保管、使用三權分立，並定期執行金鑰輪替（Key Rotation） |
| **稽核留痕** | 所有 API 呼叫紀錄完整留存，供內部稽核與外部財務審計覆核 |

### 8.2 三階段推進時程

| 階段 | 內容 | 預計時程 |
|---|---|---|
| **Phase 1：內控與財務部簽核** | 風控委員會、財務部、法遵室完成本報告會簽；完成 API 最小權限設定與資安部門覆核；制定緊急撤資 SOP | 核准後 2–4 週 |
| **Phase 2：小額 PoC 沙盒運作** | 依核准額度（建議不超過總資產 10%）啟動 Bitfinex USD Margin Funding 小額試點，實地驗證動態天期階梯機制效益；財務部每月覆核對帳與實際淨年化收益率 | 3 個月 |
| **Phase 3：正式額度配置與自研微服務接管** | 依 PoC 實際數據評估擴大至常態化 10%–15% 上限；將驗證完成之流程遷移為內部自研 API 微服務（In-house Trading Script），部署於內部 VPC | PoC 結束後 1 個月內啟動評估 |

### 8.3 治理與覆核機制

- **月度覆核：** 財務部與資產管理部聯合覆核當月出入金、利息收入與曝險集中度。
- **季度風控報告：** 提交風控委員會，內容涵蓋單一平台曝險比率、天期分佈、實際淨年化收益率與目標值落差分析，以及 CEX 活期理財緩衝池餘額是否逾越核定上限。
- **異常事件即時通報：** 平台異常出金延遲、API 異常呼叫、USDT 脫錨事件、或同業穿倉/擠兌事件，須於 24 小時內通報風控主管與財務長。
